# Sista Ai

Bertindaklah sebagai Senior Product Engineer, UI/UX Designer, Database Architect, dan Security Engineer. Bangun aplikasi web internal bernama SISTA AI (Sistem Inteligensi Surat Tugas dan Administrasi) untuk mendukung Kepala Sub Bagian Tata Usaha dalam mengotomatiskan langkah administratif Surat Tugas untuk ekstraksi data, pemilihan template, pengisian draf, pencatatan arsip). Aplikasi dibangun berdasarkan PRD yang sudah dilampirkan menggunakan kerangka kerja Next.js dan PostgreSQL untuk manajemen data yang efisien dan aman.

This project was built with [Lovable](https://lovable.dev).
